📌 About the Project
The MOBI HOUSE Grand Opening Website is a multi-page event website designed with a premium black-and-gold theme. It celebrates the store's opening and gives visitors a convenient way to view the event schedule, special offers, chief guest information, photos, video, and location details.

The website is built with HTML5, CSS3, and JavaScript and is designed to work across mobile phones, tablets, laptops, and desktop screens.

🚀 Run the Website Locally
Option 1: Open in a Browser
1. Download the website ZIP file.
2. Extract the ZIP file.
3. Open the extracted project folder.
4. Double-click index.html to open the home page in your browser.
5. Use the navigation menu to visit the other pages.
Option 2: Use Visual Studio Code
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click index.html.
4. Select Open with Live Server.
5. Test all pages, the countdown, music button, video, and mobile layout.
🌐 Deploy the Website Online
The website can be hosted on a static hosting platform such as Vercel or Netlify.
1. Extract the complete project folder.
2. Upload the folder to a GitHub repository, or import the repository into your hosting platform.
3. Ensure that all four HTML pages, style.css, script.js, and the complete assets folder are included.
4. Deploy the project.
5. Open the published website URL and test it on both a phone and a desktop.
Deployment tip: Do not upload only index.html. The other pages and assets are needed for the full website to work correctly.

🎵 Background Music: Browser Note
The website attempts to start the background music automatically. However, mobile and desktop browsers may block autoplay when audio has sound.

If the music does not start automatically:
1. Open the website.
2. Tap the small music button.
3. Use the same button to pause or resume the music.
This is a browser restriction and does not necessarily indicate a problem with the website.
