🚀 Run the Website Locally
1. Download and extract the project ZIP.
2. Open the extracted project folder.
3. Double-click index.html to open the website in a browser.
4. Use the navigation menu to visit the other pages.
5. If background music does not start automatically, tap the music play button. Some browsers block autoplay with sound until the visitor interacts with the page.
For local development, you can also open the folder in Visual Studio Code and use the Live Server extension.
🌐 Deploy Online
You can deploy the complete project folder to a static hosting service such as Vercel or Netlify.
1. Upload or import the complete project folder/repository.
2. Make sure all HTML pages, style.css, script.js, and the assets folder are included.
3. Deploy the project.
4. Open the generated website URL and test it on a phone and desktop.
📝 Customization
- Event date/time: Update the countdown target in index.html and the displayed event details on relevant pages.
- Store location: Update the location text and map destination in location.html.
- Phone number: Search for 9832749304 in the HTML files and replace it if the store contact number changes.
- Guest details/photos: Update guests.html and the relevant image files in assets/.
- Background music: Replace assets/grand-opening-audio.mpeg with your chosen audio file, keeping the path and format consistent.
- Video: Replace assets/grand-opening-video.mp4 with the desired video.
- Logo: Replace assets/mobihouse-logo.png with the official logo, keeping the same filename or updating the HTML paths.
- Colors and animations: Edit style.css.
- Page interactions and countdown logic: Edit script.js.
⚠️ Important Notes
- Background music autoplay is not guaranteed because browsers may block autoplay with sound. The on-screen play button provides a manual option.
- Test the website on multiple screen sizes before sharing it publicly.
- Confirm the phone number and event/location details before publishing.
- Make sure you have permission to publish the supplied photos, audio, and video.
